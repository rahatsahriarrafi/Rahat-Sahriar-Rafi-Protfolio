# Rahat Sahriar Rafi — Portfolio

Personal brand site for cybersecurity research, software engineering, digital forensics, and Team NullX.

## Stack

Next.js (App Router) · TypeScript · Tailwind CSS · Lucide

## Run

```bash
npm install
npm run dev
```

## Checks

```bash
npm run check:content
npm run build
```

## Content

Edit `src/data/content.ts` for copy, projects, links, and achievements.
